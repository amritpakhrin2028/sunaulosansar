**सुनौलो संसार फोटोग्राफी** | Nepal's Premier Photography Studio

## 🌟 Overview

A fully responsive, modern photography studio website built with pure **HTML5**, **CSS3**, and **Vanilla JavaScript** — no frameworks, no dependencies. Just open `index.html` in any browser.

**Design**: Bold & Modern | Dark cinematic theme | Vibrant orange accents | Smooth animations

## ✨ Features

### Pages
| Page | Description |
|------|-------------|
| `index.html` | Hero with parallax + animated stats + 6 services + gallery preview + pricing cards + testimonials |
| `gallery.html` | Full gallery with 7-category filter + lightbox viewer |
| `about.html` | Story, team, 4-step process, awards & publications |
| `contact.html` | Booking form, contact info, FAQ accordion, map |

### Design & UX
- 🌑 **Dark cinematic theme** with vibrant orange/gold accent palette
- 🖱 **Custom cursor** with smooth follower animation
- ⚡ **Preloader** with animated progress bar
- 📜 **Scroll reveal animations** (fade up, slide left/right with stagger)
- 🔢 **Animated number counters** on scroll
- 🔍 **Lightbox** with keyboard navigation (← → Escape)
- 🏷 **Gallery filter** with smooth show/hide animation
- ❓ **FAQ accordion** with smooth open/close
- 📱 **Fully responsive** — mobile, tablet, desktop
- ♿ **Accessible** — ARIA labels, semantic HTML, keyboard nav
- 🔝 **Back to top** button

### Technical
- **Zero dependencies** — no jQuery, no Bootstrap, no frameworks
- **CSS custom properties** (variables) for consistent theming
- **IntersectionObserver** for scroll animations (performant)
- **CSS Grid + Flexbox** for all layouts
- Google Fonts: **Outfit** + **Playfair Display**
- SEO: meta tags, canonical URLs, semantic HTML5, single `<h1>` per page
